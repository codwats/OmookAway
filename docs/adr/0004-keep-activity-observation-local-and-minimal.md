# Keep activity observation local and minimal

OmookAway will use only aggregate local activity transitions and today-only Break counts: no telemetry, network calls during normal operation, application or window-title tracking, raw input capture, calendar access, meeting detection, or microphone access. Richer context could make interruptions smarter, but surveillance would undermine trust for the Monotropic Workers the product serves and is unnecessary for the MVP's active-use cadence.
